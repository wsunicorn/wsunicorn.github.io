# wsunicorn.github.io

Personal portfolio of **Nguyễn Ngọc Lân** — AI Engineer (LLM · RAG · AI Agents · LLMOps), Ho Chi Minh City.

Live: https://wsunicorn.github.io · Tiếng Việt: https://wsunicorn.github.io/vi/

Built with [Astro](https://astro.build), plain CSS and a little vanilla JS. Deployed to GitHub Pages on every push to `main`.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static site in dist/
```

Content lives in `src/data/` (projects and profile, bilingual EN/VI) and `src/i18n/ui.ts` (interface strings).
